Nexus Node Web App — Personal Backups

This personal utility backs up a privately operated NexusNode installation to its operator's Google Drive using rclone. It is intended for the operator's own account.

The utility creates backup archives, uploads them to a dedicated Drive folder, reads them back to verify the upload, and removes older backups according to the configured retention settings.

Google authorization uses the drive.file permission to manage files created or explicitly authorized for this utility. It does not request access to Gmail or contacts.
